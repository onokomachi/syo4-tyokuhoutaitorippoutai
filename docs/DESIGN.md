## 1. 単元と柱
東京書籍『新しい算数4下』「14. 直方体と立方体」（p.100〜113）。学習指導要領 4年 B(1)「立方体、直方体などの立体図形」。

| 柱 | 内容 | レベル |
|---|---|---|
| ① 構成要素 | 直方体・立方体の定義、面の形と数、辺・頂点の数、等しい辺、ひごとねん土玉、厚紙で箱を作る | `kousei-*` |
| ② 平行・垂直 | 面と面・辺と辺・面と辺の平行と垂直（4年の「垂直な辺」は交わって直角になる辺だけ） | `heiko-*` |
| ③ 展開図 | 立方体になる／ならない、続きをかく（立方体・直方体）、組み立てて重なる点・辺、平行・垂直な面 | `tenkai-*` |
| ④ 見取図 | 見えない辺は点線、見取図を読む、続きをかく | `mitori-*` |
| ⑤ 位置の表し方 | 平面（横・たて）を読む・点をかく、空間（横・たて・高さ） | `ichi-*` |
| ⑥ いかそう | リボンの長さ・展開図にリボンの線（紙のテストのいかそう算数） | `katsuyo-*` |
| ⑦ エラーハンター | 下の誤概念8つ | `eh-*` |

### 紙との差
- 作図は「紙にかく」かわりに、方眼をタップして答える。
  - 展開図（大問4・5）：方眼のマスをタップ（なぞる）して面をぬる。線をかく代わりに面を置く（「どこに面を足すか」を考える部分は同じ）。折り目の点線はかかない。
  - 見取図（大問6）：格子点を2つタップして辺をひく。実線／点線をきりかえる。
  - 点をかく（大問7②）：格子点をタップ。
- 「全部書きましょう」（大問3③④）は、12本の辺のボタンから全部えらぶ形。順番は問わない（紙と同じ）。
- 紙の大問3・8は1つの図で①〜④を答えるが、アプリでは小問ごとに図を作り直す（毎回ちがう形で練習できるように）。
- いかそう算数①の「直線が上下左右にずれていてもよい」は、アプリでは真ん中を通る線だけを正解にしている（格子点の上でかくため）。
- 採点は一発正解のみ（2回目の正解は0点）。紙の部分点はない。

## 4. 正解の出し方（手作業の表を使わない）
`src/lib/solid.ts` で、展開図を「面（長方形）＋つながり方の木」として持ち、**箱を転がすのと同じ計算で組み立てる**。
- 面を右へたどると：新しい面の法線＝もとの面の「右の向き」、新しい右の向き＝もとの法線の逆…（`step`）。
- 組み立てた各面の左上の点が箱のどの点になるかも持つので、展開図の点 → 箱の頂点、辺 → 箱の辺 が計算で出る。
  - 重なる点（大問8①）＝同じ頂点になる点、重なる辺（大問8②）＝同じ辺になる外まわりの辺、平行な面＝法線が逆の面。
- 展開図の続き（大問4・5）は、のこした面に面をつなげる方法を全部数えて「正しくぬれるマスの集合」をすべて持つ（`completions`）。もとの答えと別の形でも、正しい展開図なら○。
- 6マスの形が立方体の展開図か（`tenkai-cubeok`・`eh-net`）は、となり合う辺から木を全部作って組み立てる（`foldRects`）。
- `npm run verify` が、35種類の6マスの形のうち展開図は11種類になること、立方体の展開図のまわり14本の辺が2本ずつ7組重なることを毎回たしかめる。
- 平行・垂直の答えは、頂点A〜Hの位置から辺の向き・面の法線を計算する（4年の約束どおり、垂直な辺は交わる辺だけ）。

## 5. 解答方法の工夫（kb の知見の適用）
- 練習・テスト・実力の階段・ボス戦で**同じ画面**を使う（`QuestionRound`）。
- 作図は「基準になる図」と「かく場所」を同じ1枚のSVGにまとめる（`bugs/construction-reference-figure-split-from-grid`）。
- ヒントは3段。1回目から答えは見せない。まちがえると、よくあるまちがいに合わせたひとことを出す（見えない辺を数えていない、交わらない辺は垂直ではない、横とたてが逆、など）。
- 作図はまちがえてもかいたものを消さず、直して出し直せる。かいてある線をなぞっても×にしない。2回に分けてひいた線も○（格子のかけらでくらべる）。
- 本番テスト：答え1つの問題は2回で×・次へ／複数ステップは「わからない」で降りる／一発正解のみ得点。
- 選択肢の正解位置は毎回シャッフル（verify が偏りを検査）。各項目 20通り以上（verify が数える）。
