# はこはこランド（小4 算数「直方体と立方体」）

小学4年生「14. 直方体と立方体」（東京書籍 新しい算数4下）の学習ゲーム。
**展開図はマスをぬって、見取図は点をむすんで**、作図までアプリの中で完結するように作ってある（設計は `docs/DESIGN.md`）。

## モジュール（31項目）
| モジュール | 内容 |
|---|---|
| 面・辺・頂点 | 直方体？立方体？／立方体の面・辺・頂点／直方体の面と等しい辺／ひごとねん土玉／あつ紙で箱を作る |
| 平行と 垂直 | 面と面／辺と辺の平行／辺と辺の垂直／面と辺 |
| 展開図 | 立方体になる？／立方体・直方体の展開図をかく／平行・垂直な面／重なる点／重なる辺 |
| 見取図 | 見取図を読む／見えない辺を点線に／見取図の続きをかく |
| 位置の 表し方 | 点の位置を表す／点をかく／空間の位置 |
| いかそう | リボンの長さ／リボンの線を展開図に |
| エラーハンター | まちがい8種（見えない辺の数えわすれ・6つつながれば展開図・ねじれの辺を垂直 など） |
| 本番テスト・実力の階段・ボス戦 | 紙のテストと同じ 表100点＋裏50点／単元の実力チェック／ボスとの対戦 |

## 開発
```
npm install
npm run dev        # http://localhost:3000
npm run check      # 学級ポータルのルール点検・型チェック・問題の機械検査・ビルド
npm run catalog    # 学級ポータルのカタログを書き出す
```
進捗・設定は localStorage（`rippoutai_*`）。学級ポータルへの接続は環境変数 `VITE_SUPABASE_URL` / `VITE_SUPABASE_PUBLISHABLE_KEY`（未設定なら送信しない）。
